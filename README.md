## Big Data con mis palabras
 
**Qué es Big Data:** 
Gran volumen de datos y que llegan tan rapido que las herramientas normales como excel o una BD no puede gestionar.

 
**Un ejemplo que sí es Big Data, y por qué:**
 Las búsquedas en Google. Cada segundo, gente de todo el mundo hace miles de búsquedas, y Google guarda lo que buscamos, las páginas que visitamos y nuestras preferencias. un solo ordenador jamas podria con tanta informacion
**Un ejemplo que no es Big Data, y por qué:**
 La base de datos de clientes de una empresa mediana. Puede tener miles de registros, pero crecen despacio y un servidor normal con SQL los maneja sin problema.
